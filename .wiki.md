# Project Summary
CyberShield AI is a cutting-edge web application designed to provide immediate support to victims of cybercrime in Pakistan. By utilizing advanced AI technology, the platform offers vital resources such as crime classification, evidence collection checklists, psychological support, and direct referrals to relevant authorities, aligning with the Prevention of Electronic Crimes Act (PECA) 2016. This ensures that victims receive timely and tailored assistance, effectively addressing their unique needs.

# Project Module Description
The project consists of two primary functional modules:
1. **Frontend**: A user-friendly React application that enables users to interact with the AI and access various features, including an embedded chat interface for immediate support in contexts like child safety.
2. **Backend**: A FastAPI server that manages user authentication, chat history, and AI responses.

# File Description Inventory
- **app/backend/routers/cybercrime.py**: API endpoints for managing conversations and messages related to cybercrime.
- **app/backend/models/conversations.py**: ORM model for conversation data storage.
- **app/backend/models/messages.py**: ORM model for message data storage.

- **app/frontend/src/pages/**: Contains main application pages, including chat interface and landing page.
- **app/frontend/src/components/**: UI components utilized throughout the application, including the embedded chat interface for child safety.

- **app/frontend/src/main.tsx**: Entry point for the React application.
- **app/frontend/src/components/MarkdownRenderer.tsx**: Component for rendering markdown content.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: FastAPI, PostgreSQL
- **AI**: LangChain, Google Gemini 2.5 Pro
- **Database**: SQLite for local development, PostgreSQL for production
- **Authentication**: JWT (python-jose), bcrypt (passlib)

# Usage
### 1. Install Node.js
Ensure Node.js is installed:
```bash
node --version
```
If not installed, download the LTS version from the Node.js website and install it.

### 2. Install pnpm
Install pnpm globally:
```bash
npm install -g pnpm
```

### 3. Navigate to the Frontend Directory
Open the terminal in VS Code and navigate to the frontend folder:
```bash
cd path-to-your-frontend-folder
```

### 4. Install Frontend Dependencies
Install frontend dependencies:
```bash
pnpm install
```

### 5. Build the Frontend
Build the frontend application:
```bash
pnpm run build
```

### 6. Set Environment Variables for Backend
For the backend, set the following environment variables:
```bash
export GOOGLE_API_KEY="your-google-api-key"
export SECRET_KEY="your-secret-key-for-jwt"
export DB_PATH="cybershield.db"  # optional
export CHROMA_PERSIST_DIR="./chroma_db"  # optional
```

### 7. Run the Backend Server
For the backend, run:
```bash
uvicorn main:app --reload
```
